DSH Share 安装与使用

通过 macOS 系统共享菜单，将同一台 Mac 上的文件、图片、文本和链接发送到 DeepSeek Harness。
分享内容作为附件放入 Harness 当前会话的输入区，等你手动发送。

使用条件
• macOS 13 或更新版本，已安装并可正常使用 DeepSeek Harness 桌面版。
• DMG 包含 Apple Silicon 和 Intel 两个架构；兼容性范围见项目文档。
• 使用 DMG 安装无需 Xcode、命令行工具、Python 或单独的 Node.js。

安装
1. 先打开一次 DeepSeek Harness，配置好模型和 Agent，确认能新建会话，然后按 ⌘Q 完全退出。
2. 打开 DMG，将 DSHShare.app 拖到 Applications／应用程序文件夹。
   也可以复制到自己主目录下的 Applications 文件夹，仅供当前用户使用。
   DSHShare.app 提供系统分享入口，需要固定的安装位置；请勿直接从安装磁盘运行设置助手。
3. 复制完成后，推出安装磁盘，再从应用程序文件夹打开 DSHShare。
4. 安装包未经 Apple 公证，首次打开可能被系统拦截。
   先尝试打开一次，再到“系统设置 → 隐私与安全性”，为这个 App 选择“仍要打开”。
5. 按设置助手的“准备 → 安装 → 启用共享 → 测试分享”依次操作。
   助手自动连接 Harness 桌面版，无需选择配置名称。
6. 第 3 步会自动检查接收端和共享入口。已就绪的项目显示绿色勾选；只需按未就绪项目的提示操作。
   从设置返回助手后会自动复查。两项通过后直接进入测试；无法自动确认时，也可以选择“直接测试分享”。
7. 安装前已运行的来源应用，请完全退出后重新打开。微信请使用 ⌘Q。

开始分享
• Finder：选中普通文件，右键选择“共享 → DeepSeek Harness”，点击 DeepSeek Harness的图标。
• 微信：在支持分享的内容上，选择“其它应用 → 选择电脑中的应用 → DeepSeek Harness”。
• 助手最后一步提供“显示测试文件”按钮，可以用内置的小文本文件确认安装是否成功。
• 先在 Harness 选中接收会话，再分享测试文件。
• 看到当前会话的输入区出现附件，且未自动回复，即表示接收成功。
• 可以继续补充要求；只有手动点击“发送”后才会启动 Agent。
• 设置完成后即可关闭助手，日常分享无需保持此窗口打开。

内容与隐私
• 文件直接作为附件，文本和链接作为“分享内容.txt”附件；输入区已有文字和附件会保留。
• DeepSeek Harness 未运行时会尝试打开；打开失败会报错，分享内容会保留，无需重复分享。
• 没有打开会话时，分享会等待。途中切换会话时，回到原会话继续接收。
• 模型访问、联网及工具权限遵循你的 Harness 设置。
• 支持普通文件、图片、文本和链接，不支持文件夹；每次最多 128 个文件，合计不超过 256 MiB。
• Harness 还可能有自身的附件和上传限制。
• 附件进入输入区并确认收到后，立即删除本工具的分享副本、投递状态和临时回执，不保留转发历史。
• Harness 收到的会话和附件是转发结果，由 Harness 自身管理。
• 待处理、未确认和失败内容不会按时间自动删除。
• 附件进入 Harness 后，由 Harness 管理；关闭或重新加载 Harness 可能丢弃未发送的草稿。

遇到问题
• 没有分享入口或头像不对：检查系统共享扩展，并完全退出、重新打开来源应用。
• Harness 没收到：打开接收会话，确认 dsh-share 已启用，并检查输入区的附件。
• 打开接收会话查看输入区。排查期间不要反复分享相同内容，以免重复添加附件。
• 在 GitHub 报告问题时，请说明 macOS、芯片类型、Harness 版本和具体操作，并遮盖私人信息。

更新与卸载
• 更新前完全退出 Harness 和 DSHShare，用新版 App 替换旧版，再打开并完成安装步骤。
• 安装器会保留原有配置备份；接收端自动清理已完成的转发残留。
• 卸载：先保存工作并按 ⌘Q 完全退出 Harness，再打开 DSHShare，点击“开始安装”左侧的“卸载”，确认“卸载并移到废纸篓”。
• 卸载会移除分享入口和已连接配置中的接收组件，并将 App 移到废纸篓。
• 完成后重新打开微信等来源应用以刷新缓存的共享菜单。仅需暂停接收时，在 Harness 中停用 dsh-share 即可。
