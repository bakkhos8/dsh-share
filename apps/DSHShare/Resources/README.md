# Avatar icon / 头像图标

`AppIcon.png` is the avatar icon used by DSH Share and its DeepSeek Harness Share menu entry. It is sourced from online material.

This artwork is not included in the repository's MIT license for code and documentation. The repository does not supply a separate third-party open license for the character artwork; obtain the relevant rights before reusing or relicensing it.

`AppIcon.png` 是本项目采用的头像图标，来源为网络素材。它用于本项目的应用和共享入口识别，不随代码的 MIT 许可证授予复用或再许可权利。

The native installation process packages the PNG into standard macOS icon sizes. The same icon is used by the containing app and its share extension.
The receiving plugin includes the same avatar icon as `plugin/dsh-share/icon.png` for the DeepSeek Harness plugin list, with its asset notice included in the plugin package.
